LIBRARY DESK
Node.js practical · HTTP + Express

A small space for big ideas

Every book has a place.

A library book management application demonstrating Node.js HTTP routing, static file serving with the FS module, and a REST API built with Express.

Node.js HTTP server

Runs on port 3000 and serves this page from the public folder using the FS module.

GET/books · list books GET/about · about GET/home · this page

Express REST API

Start the API on port 4000 to create, read, update, and delete books.

GET/books · all books GET/books/:id · one book POST/books · add a book PUT/books/:id · update a book DELETE/books/:id · remove a book

Run both servers

Open two terminals in the project folder and run:

npm run start:http

npm run start:api

Book records are stored in JavaScript arrays for this practical.
